02 / How they are built

Small, fast, from scratch.

The code on GitHub

Nothing to install

Open the link and play. No plugins, accounts or downloads; it all runs in the browser.

Sound made in code

Engines, wind, lasers and chimes are synthesised with the Web Audio API. No audio files.

Keyboard and touch

Every game has keyboard controls and on-screen controls for phones and tablets.

Runs on modest hardware

Graphics presets (low, medium, high) and pooled objects keep the frame rate smooth.

Records stay with you

Best laps and scores are saved in your browser, nowhere else.

Open source

Every line is on GitHub, with a design doc for each game in docs/.
